# **OS Virtual Lab**

A Python-based GUI application designed to provide an interactive learning platform for understanding operating systems and their underlying algorithms. This virtual lab offers comprehensive explanations and simulations of various OS concepts, making it an excellent tool for students and educators.

---

## **Features**
- **Interactive GUI**: Built with Python's Tkinter library for a user-friendly and intuitive interface.
- **Comprehensive OS Topics**: Learn about key operating system concepts like process scheduling, memory management, and more.
- **Algorithm Simulations**: Includes detailed simulations of algorithms such as:
  - CPU Scheduling (FCFS, SJF, Priority Scheduling, Round Robin)
  - Page Replacement (FIFO, LRU, Optimal)
  - Disk Scheduling (SCAN, LOOK, SSTF)
- **Step-by-Step Visualization**: Visualize the working of algorithms step by step for better understanding.
